TL;DR. Across the four standard Composed Image Retrieval (CIR) benchmarks — CIRR, FashionIQ, LaSCo, and CIRCO — a large fraction of test queries can be solved by retrievers that see only the reference image or only the modification text. We call these shortcut-solvable queries. CIRCUS audits all 11 public retrievers used in our study, removes the shortcuts, and releases two cleaner evaluation sets so future work can measure the part of the task that actually requires multimodal composition.

What this release ships

  • A reproducible shortcut audit — for every test query in CIRR, FashionIQ, LaSCo, CIRCO, the rank of the ground-truth target under multimodal, text-only, and image-only inputs, aggregated across 11 retrievers (9 open-source + 2 commercial APIs).
  • Dataset 1 — the shortcut-free subset (shortcut_free_subsets/): queries that no retriever could solve unimodally at K = 10.
  • Dataset 2 — the human-validated subset (final_dataset/): the subset of shortcut-free queries that human annotators judged to be well-formed CIR instances (≥ majority of annotators).
  • The full reproduction pipeline: per-retriever encoders, two unimodal ablation configs, the aggregator that turns ranks into audit labels, and the re-evaluator that computes Recall@10 and the Composition Gap on either subset.

Headline metric: Recall@10 and the Composition Gap

The headline metric is Recall@10. When a retriever is also run under the two unimodal ablations (image-only zero-image and text-only drop-text), we report the Composition Gap: 

Composition Gap = R@10(multimodal) − max( R@10(text_only_drop_text), R@10(image_only_zero_image) )

A small Composition Gap means a retriever does not benefit much from seeing both modalities — either the model is not actually composing, or the benchmark does not require it. CIRCUS lets you measure both on cleaner subsets.

Retriever pool

9 open-source + 2 commercial APIs:

  • E5-Omni, GME-Qwen2VL, LamRA, LamRA-Qwen2.5VL, MM-Embed
  • Qwen3-VL-Embedding (2B and 8B), Rzen-Embed, VLM2Vec-V2
  • Gemini Embedding 2, Voyage Multimodal 3.5

Reproduce in five stages

  1. Envs — one conda env per retriever family (envs/create_*.sh).
  2. Per-(dataset, retriever) retrieval — retrieval/run_generate_retrieval_data*.sh writes one JSON per pair with multimodal / text-only / image-only ranks.
  3. Aggregate — retrieval/aggregate_retrieval_data.py turns ranks into the shortcut-audit labels (already shipped under shortcut_audit/).
  4. Validated subset — final_dataset/build_validated_subsets.py derives final_dataset/query_jsonl/ from annotations/users/.
  5. Re-evaluation — subset_evaluation/run_subset_eval.sh writes Recall@10 (and the two ablations, when requested) per (dataset, subset, retriever) to subset_evaluation/logs/results.jsonl.

Full step-by-step instructions are in the repository README.
